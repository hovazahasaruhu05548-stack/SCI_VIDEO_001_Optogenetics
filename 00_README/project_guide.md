# SCI_VIDEO_001_Optogenetics

视频标题：《一束蓝光，为什么能控制神经元？——光遗传学是如何工作的》

本项目是待制作的AI神经科学科普视频规划包。**只包含目录与文本文件，没有生成任何真实视频、图片或音频。**

## 制作目标

- 规划总长：**00:03:43.000（223秒）**，26镜头；正式成片须保持180—240秒。
- 画幅与交付：16:9，1920×1080，30 fps，中文旁白，H.264 MP4。
- 旁白正文约806个非标点字符（含ChR2等拉丁字符）；目标平均约3.6字/秒，含自然停顿。以实际试读为准，不把文本字数当作音频时长证据。
- 默认制作方式：每镜头一张AI关键帧、一段无字无声AI视频，剪映后加科学图形、关键词、旁白与字幕。

## 素材命名与状态

每镜头使用相同编号与英文描述，例如`02_VIDEO/S01_blue_light_question.mp4`与`03_IMAGES/S01_blue_light_question.png`。
CSV中的Filename为最终视频目标文件名或明确的相对路径；图片另列ImageFilename/ReplacementImage。
PLANNED_NOT_GENERATED表示待生成，并不代表文件已经存在。图片只是生成参考或该槽位替补，不能接在对应视频后重复播放。

## 制作顺序

1. 阅读科学说明与参考资料，锁定旁白；按带时间版本试读，ChR2建议读作“C、H、R、二”，Na⁺读作“钠离子”。
2. 按prompts.md逐镜制作PNG，核对膜内外、通道位置、照光范围等关键科学信息。
3. 以审核后的PNG生成对应MP4；科学箭头、离子轨迹、图表及所有文字在剪映内按分镜另做。出现错误时重新生成或用审核过的PNG等时长替换。
4. 制作223秒中文旁白，可逐镜录制后按时间拼接；不得为强行对齐而明显加速。若自然语速需微调，以最终音频为准同步更新所有时间文件，总长仍控制3—4分钟。
5. 依照import_order.txt导入素材，再按timeline.csv分轨装配，SRT导入字幕轨；配乐可省略。
6. 核对实际旁白与52条字幕落点，再依照09_EXPORT/README.md导出。

## 时间与CSV约定

CSV时间为HH:MM:SS.mmm，Duration单位为秒；SRT使用HH:MM:SS,mmm。
时间区间左闭右开，S01从0秒开始，S26到223秒结束，相邻镜头无间隙；末帧落在结束时刻之前。
所有镜头边界为整秒，30fps时可直接对应整数帧；SRT句内切点是规划毫秒，剪映可按实际声音取最近帧。
CSV使用UTF-8 BOM，支持带逗号及换行的规范引号字段，用CSV阅读器/表格软件打开，不要逐行按逗号手工拆分。

## 剪映装配要点

timeline.csv为**人工装配参考表**，不是剪映草稿工程文件，不保证CSV直接导入时间线。
V1为26个连续镜头；T1为关键词和科学图形；A1为整片旁白；A2为可选配乐；C1为SRT字幕。
音轨与字幕从0秒叠加，不接在末镜头后面。SRT的句内时间依据文本预估，未与真实音频对齐。
标题和关键词与底部字幕避让：文字离画面边缘至少约5%，字幕推荐放在底部约10%—18%区域，白字深色描边，最多两行。
旁白保持清晰无削波；若有配乐，将其压低至听得清每个字，最终试听再决定音量。硬切优先；转场在既定镜头时段内完成，不延长总时长。
